# Spy Dota 2 — Онлайн-игра «Шпион» в сеттинге Dota 2

Многопользовательская браузерная игра в жанре социальной дедукции во вселенной **Dota 2 (Smoke of Deceit Edition)**.  
Архитектура **100% готова для бесплатного хостинга на Netlify** без отдельного Node.js-сервера.

## Стек технологий
- **Frontend**: React 19 + Vite + Tailwind CSS v4
- **Backend & Мультиплеер**: Supabase PostgreSQL (`SECURITY DEFINER` RPC-движок) + Supabase Realtime WebSockets

## Возможности игры
- Создание комнаты с **4-символьным кодом** и пригласительной ссылкой (`?room=XXXX`).
- Выбор категории (**Герои** — 16, **Предметы** — 14, **Локации** — 12), времени обсуждения (**2–6 мин**) и числа шпионов (**1–2**).
- Защищённая серверная раздача ролей с полноэкранной **анимацией дыма Smoke of Deceit**:
  - Мирные игроки видят **загаданное слово и иллюстрацию Dota 2**.
  - Шпион видит **«ТЫ ШПИОН»** и интерактивный список всех слов категории (можно вычёркивать неподходящие слова).
- **Обсуждение с синхронным серверным таймером** и досрочным голосованием.
- **Голосование**, а если шпиона раскрыли — **последний шанс угадать слово**.
- **Таблица очков**, история голосов и кнопка **«Реванш»**.
- **Авто-реконнект** (`sessionStorage` + `localStorage`), **передача прав хоста** (ручная и автоматическая), мобильная адаптация.

## Как выложить сайт в Netlify
1. Запушьте репозиторий в GitHub.
2. Зайдите на [app.netlify.com](https://app.netlify.com) → **Add new site** → **Import an existing project** → выберите ваш GitHub-репозиторий **`Spy-Dota-2`**.
3. Настройки сборки подтянутся автоматически из `netlify.toml` (`npm run build` → папка `dist`).
4. Нажмите **Deploy site** — сайт готов!
